# Upstream components whose bounds the port's layout is checked against
# (migration/scripts/gui_reference.py layout). Paths are component names from
# the interface down, as ref-gui --layout prints them; a name repeated in the
# same place is "#2", "#3", ... after the first, in tree order. Each GUI PR
# adds the components it ports, each path once. Paths after an
# "@preset <file>" line (a file in migration/corpus/gui/presets/, authored by
# migration/corpus/generate.py) are laid out with that preset loaded, and
# their fixture entries name it; the rest use the init preset. Paths after
# an "@overlay <name>" line (an overlay gui_reference.py knows) are laid out
# with it open, until "@overlay none"; their entries name it too.
