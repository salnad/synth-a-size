## 2026-10-23: G0 follow-up: mirror-only save info edit

Requested by LLM Builder. Without it, renaming a patch from the chat
reloaded the whole state through `set_state`.

**Changed**

- `EditHandle::set_info(SaveInfo)` and `Batch::set_info(SaveInfo)`: the
  preset name, author, comments, style and macro names. Upstream's setters
  (`SynthBase::setPresetName`, `setAuthor`, `setComments`, `setStyle`,
  `setMacroName`) only write `save_info_`, so this updates the mirror,
  bumps `revision()` and queues nothing. The generation stays, and a full
  queue doesn't refuse it. In a batch it rolls back with the other edits.
- The G1 editor caches the preset name by `revision()` instead of
  `generation()`, so it shows a rename.

**Tests**

- `sas-engine` `edit_bus::save_info_changes_only_the_mirror`: the mirror
  changes, the revision moves by exactly one and the generation doesn't,
  nothing reaches the consumer, and a full queue accepts it. A committed
  batch keeps it; a failed batch rolls it back. Each half fails its
  mutation (Graph Reviewer on #104): a no-op `Batch::set_info`, and
  `EditHandle::set_info` without the revision bump.
- `sas-plugin` `editor::the_preset_name_follows_renames`.

No audio path change; no-edit parity is untouched.
