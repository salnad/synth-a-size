## 2026-10-27: GUI G7d (2a), LFO shapes in the popup browser, and Save to LFOs

The second G7d PR, stacked on G7d-1 (#172): the popup browser for an LFO's
shapes, the LFO name's arrows, and the LFO editor's file items. Samples
follow in G7d-2b, which needs the audio reader to give both channels.

**The LFO section** (`port/crates/gui/src/sections/lfo.rs`)

- A press on the shape's name opens the popup browser for the user's LFO
  shapes (`*.vitallfo` under the LFOs folders), 500 × 250 at the size ratio,
  above the section with its right edge at the name's
  (`LfoSection::textMouseDown`). There are no added folders for LFOs, as
  upstream passes none.
- The arrows load the shape before or after the current file among the
  user's, wrapping round (`prevClicked`, `nextClicked`, `getShiftedFile`).
- `load_lfo_file` (`loadFile`): the file's shape, named after the file and
  remembering it (`setName`, `setLastBrowsedFile`). A file that doesn't read
  as a shape changes nothing, as upstream's caught JSON exception does.
- In upstream's order, an existing file becomes the section's current file
  before it's read (`current_file_ = file`, then the parse), so the arrows
  step on past a file that doesn't read rather than stopping at it (UI
  Reviewer, #173).
- A folder chosen for one owner isn't carried to another: `loadPresets`'
  `folder_list_->filter("")` clears a selection the new owner's folders
  don't hold, and the new owner's files are all listed, in upstream and the
  port alike. A unit test pins it.

**The LFO editor's menu** (`controls/line_editor.rs`), now upstream's
`allow_file_loading_` items between Copy and the flips:

- Paste, shown when the clipboard holds a shape (`hasMatchingSystemClipboard`,
  `LineGenerator::isValidJson`), loads it.
- Save to LFOs opens the save section for the shape: a `.vitallfo` in the
  user's LFOs folder, made if missing, written with its name and author
  (`FullInterface::saveLfo`, `SaveTarget::lfo`).
- Initialize makes the shape linear (`initLinear`).
- The clipboard reader can be replaced per thread
  (`set_clipboard_reader`), so the menu's tests don't depend on the
  machine's clipboard.

**Tests** (`tests/controls.rs`)

- `the_lfo_name_opens_the_browser_and_a_shape_loads`: the browser lists the
  user's and the bank's shapes, and a file loads named after itself.
- `the_lfo_arrows_step_through_the_users_shapes`, and
  `the_lfo_arrows_step_past_a_file_that_doesnt_read` (a broken file in
  `LFOs/`; it fails with the current file set only after a good read).
- `popup_browser` `a_folder_chosen_for_one_owner_is_cleared_for_another`.
- `the_lfo_menu_saves_and_initializes_the_shape`: Save to LFOs writes
  `LFOs/<name>.vitallfo`, and Initialize leaves two points.
- `the_lfo_menu_pastes_a_shape`, with a test clipboard; `pasted_shape`
  refuses text that isn't a shape.
- `the_lfo_menu_flips_the_shape` now expects upstream's full menu.

No audio change.
